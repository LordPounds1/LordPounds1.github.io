Fixus Uploader

Privacy Policy

Effective November 7, 2026

Fixus Uploader is a personal, non-commercial tool that runs on its owner's computer and uploads the owner's Deadlock gameplay videos to the owner's own YouTube channel. Only the owner signs in to it. This policy explains what Google user data the tool accesses and what it does with that data.

YouTube API Services

Fixus Uploader uses YouTube API Services. By signing in, you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Google user data the tool accesses

  • youtube.upload: to upload videos and set their thumbnails on the signed-in channel.
  • youtube.readonly: to read the channel ID (to make sure the upload goes to the intended channel), the descriptions of recent uploads (to avoid uploading the same video twice), and the processing status, duration, title, description, tags and privacy status of videos the tool uploaded (to confirm each upload before deleting local copies).

The tool does not request your name, email address, contacts or any other Google data. It cannot delete or edit videos that are already on the channel.

How the data is used

Google user data is used only to upload the owner's videos and to confirm those uploads. It is not used for advertising, it is not sold, and it is not used to train AI or machine learning models.

Storage and security

The tool has no servers. The OAuth token issued by Google is stored only on the owner's computer, in a file that only the owner's Windows account can read. Upload records (video IDs, upload times and processing status) are kept in local files on the same computer.

Sharing

Google user data is not shared with or transferred to any third party.

Fixus Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other data the tool processes

To prepare videos, the tool processes publicly available data on the owner's computer: Twitch broadcast video and audio, public chat messages and public Deadlock match statistics. To draft titles and descriptions, it sends short excerpts of the speech transcript and of chat messages, without usernames, to an AI service (Anthropic Claude). No Google user data is included in these requests.

Retention and deletion

The OAuth token is kept until the owner deletes it or revokes access. You can revoke the tool's access at any time on the Google Account third-party access page (also available from the Google security settings page). After that, the stored token stops working. Local upload records can be deleted by the owner at any time.

Cookies and analytics

These pages use no cookies, analytics or tracking.

Changes

If this policy changes, the new version is published on this page with a new effective date.
